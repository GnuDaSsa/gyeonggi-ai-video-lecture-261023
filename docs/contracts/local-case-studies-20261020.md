# 드론축구·화성 공모전 제작 회고 보강

## Goal
기존 2026-10-23 경기도청 HTML 강의의 디자인과 91장 내용을 유지하고 실제 로컬 제작 경험 및 화성 최종 상영본을 보강한다.

## In Scope
- 사용자 지정 gpt-6-astra / ultra의 읽기 전용 구조 점검.
- 드론축구 상영 직후 에셋 관리·주 제작 방식·공중 물리·Blender 한계·우선 기준 5장.
- 시댄스 장면 설계 뒤 화성 최종 영상과 장면 연결·참조 오염·프롬프트 수정·병목 대응 5장.
- 로컬 근거/실제 파일에 연결된 발표자노트, 노트 번호 및 이동 버튼 정합성.
- HTML/CSS/JS 정적 검증, 브라우저 렌더·이동·미디어 재생 및 파일/디코드 검증.

## Out of Scope
새 영상/이미지 생성, 기존 제작 프로젝트 수정, 예약/자동화, 전체 강의 문구 재작성, GitHub 공개 push, 공모전 제출, Drive 업로드.

## Acceptance Criteria
- 총 101장. 신규 내용은 확인된 제작 기록과 해석을 구별하고, 실패/부분 개선을 완전 성공으로 꾸미지 않는다.
- 화성 최종본은 Claude 작업 이력과 답변으로 식별 후 복사·해시 검증한다. 원본 보존.
- 16:9 데스크톱과 390px 모바일에서 신규 내용/컨트롤 잘림 없음.
- 노트 각 장 제목/번호가 index.html과 일치. 숫자 하드코딩 점프는 안정적인 ID로 변경.
- 자동재생 없음. 다른 장표로 이동하면 영상 일시정지.
