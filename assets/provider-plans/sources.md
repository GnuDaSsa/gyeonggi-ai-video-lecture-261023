# 50쪽 서비스 구독 화면

확인·캡처: 2026-10-20 (Asia/Seoul). 공식 공개 요금 페이지의 실제 UI. 결제·가입 실행 없음. 캡처의 결제 주기는 화면 표기 기준. Higgsfield는 연간 환산 표시가 포함되고 Runway·Artlist는 월간 선택 화면, ZCRE는 월간 구독.

- Higgsfield: https://higgsfield.ai/ko/pricing — 개인 Starter/Plus/Ultra, 월간·연간 전환, 매월 크레딧 및 모델별 혜택.
- Runway: https://runway.com/pricing — Free, Standard, Pro, Max. 월간·연간 결제, 월 크레딧 및 동시 생성 수 구분.
- Artlist: https://artlist.io/page/pricing/max — AI Starter, Core, Creator. 월간·연간 전환과 크레딧. 연간 선택 시 일부 플랜의 지정 모델 Unlimited 표기 확인; 월간 캡처에는 해당 무제한 표기 없음.
- ZCRE: https://www.zcre.co.kr/credits — Starter/Creator/Pro/Expert. 원화 월간 구독, VAT 포함, 매월 자동 갱신, 매 결제주기 크레딧 지급.

요금 상세보다는 구독 구조를 소개하는 장표. 캡처 버튼은 로컬 확대 대화상자만 열며 외부 페이지로 이동하지 않음.
