# 성남 독립운동가 제작 경험 추가

## Goal
성남 독립운동가 제작 경험 3장을 유지하면서, 사용자 후속 요청에 따라 기존55장 `lecture-055`를 삭제하고 기존58장 `case-independence-style`을 2×2 작풍 비교와 선택 이유로 개편한다. 추가로 원본49장 뒤 첨부 현장 영상을 넣고 원본59장 뒤 영상 활용 결과를 추가한다. 현장 영상 삽입과55장 삭제가 상쇄되어 독립운동가 사례57–59장은 유지, 활용 결과는60장이다.

## Scope
- 사용자 경험은 사용자의 이번 발언을 기준으로 보존한다.
- 최신 교정: 보훈 주제이므로 익숙한 일본풍 대신 진중한 수묵화 작풍을 선택. 성남의 시작·복귀 구간은 과거와 현재의 느낌을 구분하려고 자글거리는 질감보다 깔끔한 선의 작풍을 시도. 질감 실패→그림책풍으로 대체했다는 설명을 주서사로 쓰지 않는다.
- 57장은 사용자 후속 요청에 따라 비교 설명 대신 영상 상영으로 전환한다. 위에 소제목 `시댄스로 만든 두번째 작품`, 아래에 큰 영상 플레이어를 배치한다.
- 발견한 7/28 메일용 내보내기 파일을 재인코딩 없이 복사해 사용한다. 원본 경로·해시·영상 내용·길이·코덱·전체 디코드를 확인한다. 공식 최종 마스터 승인이나 발송 완료로 확대하지 않는다.
- 독립운동가 사례는 「그날의 불빛, 성남」 인수인계 기획서, 초기·후기 제작 이미지, 7월 후속 작업 기록으로 설명한다.
- 현재57–59장: 성남시 독립운동가 영상 / 왜 이 작풍을 썼나 / 영상 생성 전에 기획부터.
- 작풍 비교는 기존 일본풍 MV, 초기 수묵화, 후기 과거 봉화, 현재 복귀 공원의 기존 이미지4개를2×2로 배치. 보훈의 진중함과 과거·현재를 구분하려는 선택 이유를 짧게 쓴다. 초기·후기 및 복귀용 이미지의 구별은 유지한다.
- 7/25–27 제작 세션에서 찾은 PNG83개의 파일 목록을 남기고 그중8장을 원본 그대로 강의에 복사한다. 초기1장과 합쳐9장 갤러리를 제공한다.
- 삭제 전104장 중 `lecture-055`만 삭제. 화성 설명4장과 원본98장을 후처리4장으로 교체. 그 밖의 장표 본문·순서 보존, 최종104장. 러닝번호·발표자노트·README·검증 갱신.
- 원본57장 `lecture-057`은 현재61장으로 이동. 제목은 보존하고 발표자 노트에 애니메이션 선택 이유로 연결하는 설명만 추가.

## Boundaries
- 새 이미지·영상 생성, 원본 프로젝트 수정, GitHub push·배포 없음. 첨부 영상은 컨테이너 변환만 허용.
- 이번 후속 요청은 독립운동가 영상 상영을 포함한다. 새로운 편집·메일 발송·공개 업로드는 하지 않는다.
- 초기 수묵담채, 7/22 중간 작풍 재설정, 7/25–27 후기 제작을 구별한다. 7/28 사용자 완료 보고를 반영하되 특정 최종 MP4·개별 컷의 최종 채택·감수·배포를 검증했다고 쓰지 않는다.
- 보훈·복지는 사용자가 설명한 작업 주제 변화다. 독립운동가 영상을 별도 복지 정책영상으로 단정하지 않는다.
- 같은 성남 이름의 저출생/취임식/푸드테크 영상과 혼동하지 않는다.
