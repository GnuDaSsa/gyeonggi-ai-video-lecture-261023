## 2026-10-20 — 최종 영상과 제작 중 증거의 분리

- 사용자의 “클로드한테 물어봐”에 따라 기존 Claude 작업 맥락에 질의해 `1008(1)_grade_v2_4K_info_v5.mp4`를 최종본으로 확인했다.

- 후보 이미지·실패 기록·샘플 QC는 제작 과정 설명용이다. 최종 영상에 모두 채택됐거나 전체 성공으로 승인됐다고 쓰지 않는다.
- 실제 제작 프롬프트는 원문을 보존한다. 효과는 관찰된 부분 개선까지만 설명하고 시간·비용 절감 수치를 추정하지 않는다.
- 이번 작업은 로컬 반영이다. 공개 GitHub push·업로드·공모전 제출은 하지 않는다.

- 로컬 초기 이미지와7/25–27 후기 이미지8개를 원본 그대로 사용한다. 새 이미지를 만들어 과거 증거처럼 넣지 않는다.
- 작풍 설명은 최신 사용자 교정을 우선한다: 보훈의 진중한 수묵화, 과거와 현재를 구분하기 위한 성남 시작·복귀의 깔끔한 선. 질감 문제·중간 재작업은 증거문서에만 보존하고 강의 중심 서사에서 제외한다.7/28 사용자 완료 보고와 특정 최종 MP4·개별 컷 채택·감수·배포 검증은 구분한다.
- runtime 폴더 부재만으로 자료 유실이나 미완성을 단정하지 않는다. 구 Codex 이미지 폴더83개와 같은 세션의 프로젝트 경로 지정 기록을 대조했고, 목록을 남겨 후속 탐색에 사용한다.
- 기존 갤러리 컴포넌트를 재사용해 초기1+후기8장 확대를 제공한다. 새 라이브러리나 생성 서비스는 도입하지 않는다.
- 사용자 후속 요청에 따라57장은 비교 설명 대신 `시댄스로 만든 두번째 작품` 소제목과 큰 영상 플레이어로 변경.7/28 메일용 내보내기본을 재인코딩 없이 포함하고58–59장 작풍·기획 설명은 유지. 공식 최종 마스터로 과장하지 않는다.
- 로컬 영상 탐색 실패의 원인이 파일이 아닌 기본 서버의 Range 미지원임을 확인해, 영상 변환 대신 작은 표준라이브러리 미리보기 서버를 추가했다.127.0.0.1만 바인딩하고8개 단위 테스트 및 실제120/210초 탐색으로 확인. HEAD·조건부 요청은 기본 핸들러로 위임한다.

## 2026-10-21 — 실제 장표 대응·제작 과정 구체화
- 사용자가 보고 있던 페이지 번호와 파일이 달라 실제 브라우저 목차의 제목·안정ID로 대상을 결정. 요청 범위 외 본문은 보존하며 이동·삽입·삭제 뒤 번호와 노트를 다시 맞춘다.
- 푸드테크는 기존 승인 시트와 재제작 승인 시트로 비교하되, 노이즈만 없앤 통제 비교나 최종 만족으로 과장하지 않는다.

- 화성 효과·소개 자막은 각각 실제 최종본4장면, 클릭 확대를 제공. 기존 최종영상과 원본 프로젝트는 변경하지 않는다.
- Runway·개발자 도구·검수 파일3장을 Codex 자동화 뒤로 이동. 그 세 장표 본문은 번호 외 동일함을 비교했다.
