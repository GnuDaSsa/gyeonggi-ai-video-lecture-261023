## 구현 시 주의

- 장표를 추가할 때 이동 버튼을 숫자에 묶지 말고 `data-go-id`를 사용한다. 보이는 러닝번호·노트·목차도 검증한다.
- 기존 `.prompt-ui-open`은 피지 전용이다. 다른 사례의 실제 프롬프트와 섞지 않는다.
- 동적 canvas 장표의 노트는 정적 텍스트 추출만으로 만들면 비어 있을 수 있다. 실제 단계·버튼·설명용 시각화 여부를 확인한다.
- 미디어는 Git LFS. 포인터만 내려받은 상태를 파일 존재만으로 통과시키지 않는다.
- 파일을 원본 수정 시각까지 보존해 덮어쓰면 로컬 서버의 조건부 캐시로 예전 이미지가 보일 수 있다. 결과 이미지를 직접 확인한다.
- 로컬 시연은 `python3 scripts/serve.py`를 쓴다. 기본 `python -m http.server`의 Range 미지원으로 독립운동가 영상 탐색이0초로 돌아갔고,206응답 서버로 바꿔 해결했다. 루프백8765가 기본이며 `--port`로 변경.
